# Graph Conditioned Diffusion for Offline Multi-Agent Reinforcement Learning

In this directory, we provide the three necessary codebases for reproducing the results of the experiments discussed in our paper. 

- `gcd`: Contains the source code for running our method **GCD** and the **MAD** baseline.
- `HiSSD`: Contains the source code for running the **HiSSD** and **ODIS** baselines. 
- `Offline_MARL`: Contains the source code for running the standard offline MARL baselines in our paper including **MA-CQL**, **MA-ICQ**, **MA-IQL**, and **OMAR**.

Please refer to the documentation in each of these codebases for installing and running. Typically, this will require different environments and dependencies per codebase.
